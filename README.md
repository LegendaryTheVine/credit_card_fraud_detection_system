# Credit Card Fraud Detection: ML Course

Instructor repo for a 3-week, 15-session one-on-one executive ML course (see `curriculum/`).

- `curriculum/` - the course outline
- `instructor/` - private: lesson plans, solutions, rubrics, review tools, scripts
- `student/` - the template the student receives; published to a separate student repo

See `instructor/README.md` for how to publish and review.

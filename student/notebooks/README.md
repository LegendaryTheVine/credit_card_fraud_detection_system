Days 1-2 have no code, Days 12-13 are built in `app/`, and Days 14-15 are written in `docs/`.

Run the notebooks from this folder: the setup cell adds the repo root to the path so `from src... import ...` works. Reusable code (splitting, scaling, training, metrics) belongs in `src/`, not copied between notebooks.

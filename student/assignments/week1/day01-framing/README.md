## Questions (answer in `submission.md`, a few sentences each)
1. In your own words, what is the difference between a rule-based system and a machine learning system? Give one fraud example a rule would catch well and one it would miss.
2. For credit card fraud detection, write down: the **input**, the **output**, what counts as **correct**, and what it costs to be **wrong** (in both directions).
3. What is the difference between supervised and unsupervised learning? Describe a fraud situation where each one is the better choice.
4. This project builds both kinds of model. Why not just one?
5. You are the head of fraud at a bank. In 3-5 sentences: what do you want this model to do for you, and what would make you shut it off?

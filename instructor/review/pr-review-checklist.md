# PR review checklist

- [ ] Branch is named for the day and the PR targets `main`
- [ ] PR template is filled in
- [ ] `submission.md` completed
- [ ] Code runs from a clean environment (`pip install -r requirements.txt`)
- [ ] No data files or model binaries committed
- [ ] Reviewed against the day's rubric in `instructor/rubrics/`
- [ ] Feedback left using `feedback-template.md`
- [ ] Approve and merge, or request changes
- [ ] Update `instructor/progress-tracker.md`
